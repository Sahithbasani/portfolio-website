# sahith.dev

Production portfolio for Sahith Basani, built with Next.js 15, React 19, strict TypeScript, MDX support, and a reusable content system.

## Local development

```bash
npm install
npm run dev
```

Validation: `npm run format:check`, `npm run typecheck`, `npm run lint`, `npm run test`, and `npm run build`.

## Content and privacy

- Experience, skills, education, location, and summary are sourced from the supplied resume.
- Public pages intentionally omit Sahith's phone number.
- The original resume PDF is not shipped because it contains that private number. Add a separately sanitized PDF at `public/sahith-basani-resume.pdf` before introducing a download link.
- Articles restructure supplied source documents and do not claim publication, peer review, acceptance, or unverified outcomes.

## Deployment

The app is compatible with Vercel. Connect the repository, select this branch, and point `sahith.dev` after a successful production deployment.
